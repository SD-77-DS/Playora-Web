Data Safety

Reference answers for the Google Play Console data safety form, based on the app's actual implementation. Last updated November 16, 2026

Accessing media on the device is not the same as collecting or sharing it. Data is "collected" only when it leaves the device.
QuestionPlayora's answer
Does the app upload videos or audio files to a server?No. Files are read and played on the device only.
Does it collect device identifiers?No.
Does it collect analytics?No. No analytics SDK is included.
Does it use third-party advertising SDKs?No.
Does it collect crash reports?No. No crash-reporting SDK is included.
Does it collect personal info, location, contacts or financial data?No.
Is any data shared with third parties?No.
Is data encrypted in transit?Playora sends no user data. Streams are fetched from the server you choose, over HTTPS when the link uses it.
Can users request data deletion?Nothing is stored off-device. Local data is removed by clearing storage or uninstalling.

Suggested form selections

  • Data collected: None
  • Data shared: None
  • Security practices: no data collected, so no account or deletion mechanism is needed.

Re-check these answers whenever an SDK is added (for example analytics or AdMob).
