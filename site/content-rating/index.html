Content Rating

Reference answers for the Play Console content rating questionnaire. Last updated November 16, 2026

Playora is a media player. It plays media the user already owns or links to, and it does not publish or host any content itself.

CategoryAnswer

Provides access to content the user choosesYes. The user supplies local files or URLs; the app does not curate content.

Because the app plays user-selected media, it generally receives the lowest age rating. Answer the questionnaire based on the app's own behavior.
